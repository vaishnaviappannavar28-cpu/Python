# Python

## Project Overview

This project demonstrates data cleaning using Python and Pandas. The dataset was cleaned by handling duplicates, missing values, inconsistent phone number formats, unnecessary columns, and text formatting.

## Tools Used

- Python
- Pandas
- NumPy
- Jupyter Notebook

## Data Cleaning Tasks

- Removed duplicate records
- Removed unnecessary columns
- Cleaned phone numbers
- Standardized text values
- Handled missing values
- Split address fields
- Reset index

## Dataset

Customer Call List Dataset

- Python_Data_Cleaning.ipynb
- Customer Call List.xlsx
